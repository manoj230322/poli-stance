# Multilingual Indian Political Posts Analysis

## Overview
This project develops a novel multilingual political stance detection system by integrating **mBERT**, various BERT models, and LSTM networks, achieving **94.6% accuracy** in identifying nuanced political sentiments from Indian social media posts (English, Hindi, Hinglish, Bengali). It combines advanced natural language processing with image analysis to predict topical stance and political leaning around the 2024 Indian elections.

## Key Features
- Comprehensive custom dataset of 3000+ tweets in multiple Indian languages  
- Deep learning models: mBERT, IndicBERT, XLM-RoBERTa, LSTM, and fine-tuned idefix-9B for image analysis  
- Multilingual sentiment and stance prediction on Twitter and Reddit data  
- Outperforms traditional baselines like Naive Bayes and SVM

## Goal
Provide political analysts and researchers with accurate tools to assess electoral behavior and public opinion through multilingual social media analysis.
